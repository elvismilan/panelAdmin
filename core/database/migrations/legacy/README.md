# Migraciones legacy

Esta carpeta conserva las migraciones históricas previas al baseline core ordenado.

## Uso

- No forman parte del flujo activo de instalación.
- Se conservan como referencia técnica y trazabilidad.
- Si un entorno antiguo ya las ejecutó, deben tratarse como historial legacy.

## Baseline activo

El baseline activo vive en `core/database/migrations/`.
